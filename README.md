# AI Ready Schools – UX Redesign

## Overview
This project is a redesign of the AI Ready Schools website as part of an assessment. The goal was to improve clarity, usability, and overall user experience.

---

## Problems Identified

- Confusing product names like Cypher, Morpheus, Zion without clear meaning
- Overloaded navigation with unclear structure
- Poor differentiation between sections (AI for Schools vs Our AI Platform)
- Hero section that didn’t communicate value clearly from a non-techie perspective.


---

## Solutions Implemented

- Simplified navigation into:
  - AI Companions
  - AI Hubs
- Added clear labels:
  - For Students
  - For Teachers
  - For Schools
- Improved dropdown usability (hover + click support)
- Redesigned hero section with clear messaging
- Introduced card-based layout for product explanation


---

## Key Design Decisions

- Prioritized clarity over complexity
- Focused on navigation and hero section as high-impact areas
- Simplified language for non-technical users (school admins)
